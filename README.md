# Bhajan_Schedular
Bhajan schedular for Sri Sathya Sai Seva Organisations, Gandhinagar. 


# STart the Engine
node main.js

# Top Run the Planner:

Submit Form: http://localhost:8000/submit-form
Plan View: http://localhost:8000/plan-view


# Installation
| Step 1: Install Node.js from https://nodejs.org/
| Step 2: Restart your Terminal
| Step 3: cd ~\Bhajan_Schedular
| Step 4: Verify 
$ node -v

| Step 5: Install dependencies
$ npm install

| Step 6: Run your App
$ node main.js
